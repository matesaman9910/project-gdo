Project GDO

Dvojice webových aplikací inspirovaných Stargate GDO/SGC. Listener (základna) ověřuje příchozí kódy z Realtime DB a umí vyhlásit alerty (např. CODE 9). Transmitter (ruční GDO) anonymně odesílá kódy na zvolenou frekvenci — s cooldownem.

SGC Listener

Poslech frekvencí, verifikace kódů, přepínač alertů (CODE 9), admin správa kódů.
Vyžaduje Google přihlášení

GDO Transmitter

Anonymní odesílač kódů na vybranou frekvenci. Vizualizace „šifrování“ + 10s cooldown.
Bez přihlášení
Frontend: čisté HTML/CSS/JS • Backend: Firebase Realtime DB + Auth • Host: GitHub Pages
