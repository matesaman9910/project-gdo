Project GDO

Dvě webové aplikace inspirované Stargate GDO/SGC. Listener (po přihlášení Googlem) poslouchá frekvence, ověřuje kódy a umí vyhlásit/ukončit alerty (CODE 9). Transmitter (ruční GDO) anonymně odesílá kódy na zvolenou frekvenci — s cooldownem a zobrazuje plnoobrazovkový alert overlay při CODE 9.

SGC Listener

Poslech, verifikace, přepínání alertů (CODE 9), správa kódů.
Vyžaduje Google přihlášení

GDO Transmitter

Anonymní odesílač kódů. Vizualizace „šifrování“ + 10s cooldown. Zobrazuje alert overlay.
Bez přihlášení
HTML/CSS/JS • Firebase Realtime DB + Auth • Host: GitHub Pages
